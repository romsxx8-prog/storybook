# استوری بوک «خونه گل‌ها و رُزا» (نسخه ترسناک)

نسخه شخصی و ترسناک داستان یاسین و آیدا.

## داستان چیه؟
یاسین و آیدا میرن سراغ یه خونه قدیمی با باغچه پر از گل‌های رنگارنگ.
ولی روح صاحب قبلی (رُزا) هنوز اونجاست — و این بار مهربون نیست.
داستان پر از حس تهدید، تنهایی روح، و ترس واقعی‌ست.
در عین حال رابطه یاسین و آیدا خیلی شخصی و نزدیک نشون داده می‌شه؛ ترس باعث می‌شه بیشتر به هم بچسبن.

## ویژگی‌ها
- لحن کاملاً محاوره‌ای و شخصی (آیدا جونم و دیالوگ‌های واقعی)
- حس ترسناک از اول تا آخر (دیگه پایان شیرین و دوستانه نداره)
- ۱۲ صفحه با رازهای مخفی
- تصاویر متناسب با فضای تاریک و باغچه

## اجرا
فایل `index.html` رو باز کن.

ساخته شده برای یاسین و آیدا.
